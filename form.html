Form

Definition

A form is a component made of input fields, such as text boxes, dropdowns, and checkboxes, plus a submit button. It lets users type or choose information and send it to the website, for example to sign up, log in, or contact you.

Live demo: contact form

Try submitting it. This is only a demo, so nothing is actually sent.

Common uses
  • Contact and inquiry pages
  • Sign up and login
  • Checkout and payment
  • Surveys and feedback
Used on websites like
Facebook (sign up)Lazada (checkout)Google Forms
When to use
  • You need information from the user
  • Users need to send you a message
  • You need accounts, orders, or bookings
When to avoid
  • Asking for more fields than you need
  • When a simple link or button is enough
  • Collecting sensitive data without proper security
Portfolio tip

Can this be used in a portfolio?

Yes, it is ideal for a contact section. Keep it short: name, email, and message. This demo does not send real emails. To make it work, connect it to a service such as Formspree or EmailJS.
