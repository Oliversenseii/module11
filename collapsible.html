Collapsible Text

Definition

Collapsible text, also called an accordion, is a component where each section has a title that can be clicked to show or hide its content. It keeps long pages short and organized, and users open only what they need.

Example

Live demo

Click a question to open or close its answer.

What is a UI widget?
A small, reusable piece of interface that does one specific job, such as a slider, a form, or a menu.
Does it need JavaScript?
No. This demo uses the built-in HTML details element, so it opens and closes without any JavaScript.
Can I change how it looks?
Yes. It is plain CSS, so you can change the colors, borders, fonts, and spacing to match your own design.
Common uses
  • FAQ sections
  • Help centers and documentation
  • Product details and specifications
  • Mobile menus and settings

Apple SupportShopee Help CenterWikipedia (mobile)
When to use
  • The page has a lot of text
  • The content is split into clear topics
  • Most users need only one or two sections
When to avoid
  • Key information everyone must read
  • Very short content
  • Content users need to compare side by side
Portfolio tip

Can this be used in a portfolio?

Yes. It works well for an FAQ, a list of services, or your work experience and skills. The page stays clean while anyone who wants the details can open them.
