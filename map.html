Map

Definition

An embedded map is an interactive map placed directly inside a web page, usually from a service such as Google Maps. Visitors can zoom, drag, and explore a location without leaving your site.

Example

Live demo: Dasmariñas, Cavite

You can drag and zoom the map below.

Requires an internet connection. To show another place, change the text after q= in the iframe src.

Common uses
  • Store or office location
  • Branch finders
  • Contact pages
  • Travel and event guides
Used on websites like
GrabFoodpandaAirbnbRestaurant and mall sites
When to use
  • Visitors need to find a physical place
  • You have one or more branches
  • Directions or distance matter
When to avoid
  • Online-only businesses
  • Privacy concerns, such as a home address
  • Pages that must load as fast as possible
Portfolio tip

Can this be used in a portfolio?

Yes, but it is optional. Add it if you are a freelancer serving a specific area or you run a local business. Show only the city or area, never your exact home address.
